# Derived Kreol resources

Generated by the scripts in `data/kreol-dataset/scripts/`. Nothing here is human
reviewed. Status labels: `external_morisienmt`, `external_kaikki`,
`external_candidate`, or (for our own drafts) `draft_generated`. None of it is
`owner_reviewed` or `ported_reviewed`.

## What is committed and what is not

Committed (ours, or aggregate facts):

- `reports/` - audit and evaluation numbers (counts only, no dataset text)
- `copy/` - AI-drafted Kreol for signal labels, actions and the UI audit (drafts for later human review)
- `style-guide-draft.md`

Not committed (`data/.gitignore`), recreate locally:

| File | Source | Why not committed |
|---|---|---|
| `morisienmt-clean/lexical/rejected.jsonl`, `suspected-misaligned-morisienmt.csv`, `../evaluation/kreol/morisienmt-dev.jsonl` | MorisienMT (Dabre & Sukhoo, AACL 2022 Findings) | released "for research purposes"; no explicit license found, so the sentences are not redistributed |
| `lexical-resource.jsonl`, `spelling-variants.classified.json`, `candidate-spelling-variants.csv` | Kaikki.org (Wiktionary extract) | Wiktionary content is CC BY-SA (share-alike); attribution: kaikki.org / Wiktextract, Tatu Ylonen |
| `../kreol-dataset/additional/` | the two raw downloads | same as above |

## Recreate

1. Put `2022.findings-aacl.3.Dataset.zip` (MorisienMT) and
   `kaikki.org-dictionary-MauritianCreole.jsonl` in `data/kreol-dataset/additional/`.
   Sources: https://aclanthology.org/2022.findings-aacl.3/ and
   https://huggingface.co/datasets/prajdabre/KreolMorisienMT ; https://kaikki.org/
2. From `data/kreol-dataset/`:

```bash
python scripts/morisienmt_audit.py
python scripts/kaikki_audit.py
python scripts/build_variant_resource.py
```

The backend works without these files: the normaliser falls back to a small
built-in table (`nu/pu/u`), and retrieval simply has no external sentences.
